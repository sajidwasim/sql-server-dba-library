# Security Policy

Do not report credentials in public issues. Rotate any credential that was committed or shared in plaintext, even if it was later redacted.

This repository must remain private until secret scanning, history review, provenance review, and quarantine rules are complete.

Security-sensitive findings include credentials, internal topology, public IP rules, unsafe dynamic SQL, privilege escalation, `xp_cmdshell`, file deletion, destructive DDL/DML, forced failover, TDE removal, and cross-tenant data exposure.
